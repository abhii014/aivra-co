# aivra.co — Cinematic Luxury Digital Flagship

> Made to Shine, Just Like You ✨

A modern, scroll-driven luxury e-commerce experience for **Aivra** (`aivra.co`), crafted with high-taste editorial pacing, warm alabaster & velvet bordeaux aesthetics, and a Saze-style Instagram DM Concierge Checkout flow.

---

## 💎 Features

- **Multi-View Architecture**: Seamlessly switch between **Home**, **Collections**, and **Reviews** in a unified interactive application.
- **Lenis Smooth Scroll & GSAP Motion**: 60fps buttery-smooth inertia scrolling and interactive caustic light refractions on jewelry centerpieces.
- **Brand Palette DNA**: Warm travertine alabaster (`#FBF6F0`), velvet bordeaux wine (`#781926`), and champagne 18K gold (`#C5A059`).
- **Exact Goa Brand Fidelity**: Complete with all product categories, real ₹ INR pricing, verified customer reviews (4.8★), and Goa shipping attribution.
- **Saze-Style Instagram DM Checkout (`@aivra.co`)**:
  - Automatically generates an order summary with unique reference tokens (`#AIV-XXXX`).
  - Calculates live subtotal in INR (`₹`).
  - Formats an Instagram Direct Message order sheet.
  - One-click copy & instant launch to `https://ig.me/m/aivra.co`.

---

## 🚀 Running Locally

You can run this project with any local static server:

```bash
# Using Python
python -m http.server 8080

# Or with Node.js
npx serve
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

## 🛠️ Stack

- **Tailwind CSS** (Utility-first styling & custom glassmorphism)
- **Lenis** (Smooth inertia scrolling)
- **GSAP & ScrollTrigger** (Scroll choreography)
- **Web Audio API** (Gentle synthesized luxury interaction chime)
